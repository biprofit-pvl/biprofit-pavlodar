B.I.Profit | Павлодар — бесплатный запуск и Google

1. Загрузите файлы index.html, biprofit-logo.jpg, robots.txt и sitemap.xml на бесплатный статический хостинг, например GitHub Pages.
2. После публикации получите точный адрес сайта. Пока адрес неизвестен, в robots.txt и sitemap.xml стоит YOUR-SITE-ADDRESS.
3. Замените YOUR-SITE-ADDRESS на фактический адрес сайта без лишних слэшей. Например, если сайт опубликован по адресу https://example.github.io/biprofit-pavlodar/, в sitemap укажите полный адрес именно этой страницы.
4. Проверьте, что главная страница открывается в браузере, а также доступны /robots.txt и /sitemap.xml. Для GitHub Pages в подпапке пути файлов должны учитывать название репозитория.
5. Откройте Google Search Console: https://search.google.com/search-console/
6. Добавьте сайт как URL-префикс (это удобнее, когда нет собственного домена). Подтвердите владение одним из предложенных Google способов. Для GitHub Pages может потребоваться добавить HTML-файл подтверждения в корень опубликованного сайта.
7. В Search Console откройте «Файлы Sitemap» и отправьте sitemap.xml (если путь в конкретном адресе отличается — укажите фактический путь).
8. Используйте «Проверка URL», вставьте полный адрес главной страницы и нажмите запрос на индексирование.

Важно:
- Google не гарантирует индексацию и позиции только потому, что sitemap отправлен.
- Бесплатный адрес вида username.github.io подходит для старта, но выглядит менее корпоративно, чем собственный домен.
- Это статический сайт. Форма готовит сообщение для отправки через WhatsApp или почтовое приложение; она не сохраняет заявки в базе автоматически.
- Перед публикацией проверьте контактные данные, права на логотип и изображения, а также корректность описаний продукции.
